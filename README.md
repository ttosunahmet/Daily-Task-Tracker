# ✅ Daily Task Tracker

A terminal-based personal productivity and habit tracking application developed in Python. Actively developed and open to all kinds of improvements.

## 📌 About

Daily Task Tracker is a console application that helps you set daily goals, track completion and build consistent habits over time. Built from scratch using core Python concepts.

## 🚀 Current Features

- Daily goal input and tracking
- Task completion confirmation (yes/no)
- File-based progress logging
- Support for multiple task categories (reading, sports, english, etc.)
- Streak tracking system

## 🛠️ Technologies Used

- Python
- File I/O
- Functions & Conditionals

## ▶️ How to Run

```bash
python main.py
```
